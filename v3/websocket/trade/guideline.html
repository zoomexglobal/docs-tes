Websocket Trade Guideline

Place, amend and cancel orders over a persistent connection. This channel is not the public market stream, and it is not the private order stream.

Trading products covered: Spot / Linear / Inverse

  • Mainnet: wss://stream.zoomex.com/v5/trade
  • Testnet: wss://stream-testnet.zoomex.com/v5/trade

retCode=0 means the request was accepted. It does not mean the order is filled. Use the private order topic on wss://stream.zoomex.com/v3/private (testnet: wss://stream-testnet.zoomex.com/v3/private) to track order status.

Batch order ops and order.cancel-all are not supported on this connection. Sending them returns retCode=10404 and retMsg=op not found. Cancel all orders with the REST endpoint Cancel All Orders.

Account rate limits are shared with the matching REST paths. See the Trade rate limit table. order.create, order.amend and order.cancel are each 10 requests per second.

Authentication​

Send auth within 10 seconds of connecting. Otherwise the server closes the connection.

The signature string is GET/realtime concatenated with expires. expires is a millisecond timestamp and must be greater than the current time. Do not send the REST X-BAPI-SIGN header on this connection. The same algorithm is shown on Connect.

ParameterRequiredTypeComments
reqIdfalsestringMatches the response. Maximum length 36
optruestringauth
argstruearray[apiKey, expires, signature]

Successful response: retCode=0, retMsg=OK, op=auth, and connId for this connection. reqId is returned when the request includes it.

A second auth on the same connection returns retCode=20001, retMsg=repeat auth.

The API key must have trade permission. A read-only key fails with retCode=1002. If the key is deleted, or its bound IP changes, the server closes the connection. Connect and authenticate again.

import hmac
import json
import time

def send_auth():
    key = "XXXXXXXX"
    secret = "XXXXXXXX"
    expires = int((time.time() + 10) * 1000)
    signature = hmac.new(
        bytes(secret, "utf-8"),
        bytes(f"GET/realtime{expires}", "utf-8"),
        digestmod="sha256",
    ).hexdigest()
    print(json.dumps({
        "reqId": "auth-001",
        "op": "auth",
        "args": [key, expires, signature],
    }))

Request Example​

{
    "reqId": "auth-001",
    "op": "auth",
    "args": [
        "XXXXXX",
        1711010121452,
        "ec71040eff72b163a36153d770b69d6637bcb29348fbfbb16c269a76595ececf"
    ]
}

Response Example​

{
    "reqId": "auth-001",
    "retCode": 0,
    "retMsg": "OK",
    "op": "auth",
    "connId": "cnt5leec0hvan15eukcg-2t"
}

Create / Amend / Cancel​

Business fields are documented on the order pages. Put exactly one order object in args.

  • Place Order: order.create
  • Amend Order: order.amend
  • Cancel Order: order.cancel

Use the same symbol you use on REST. symbol in the examples below is BTCUSDT.

ParameterRequiredTypeComments
reqIdfalsestringMaximum length 36. Must be unique on this connection, or the response is 20006. If omitted, the response still returns a server-generated value
headertrueobjectRequest header
> X-BAPI-TIMESTAMPtruestringCurrent timestamp in milliseconds
> X-BAPI-RECV-WINDOWfalsestringDefault 5000. serverTime - recvWindow <= timestamp < serverTime + 1000
> RefererfalsestringOptional. Forwarded as sent
optruestringorder.create, order.amend, order.cancel
argstruearrayExactly one order object

A timestamp outside the window returns retCode=1004 and is not forwarded. Do not put X-BAPI-SIGN or X-BAPI-API-KEY in header.

Ping​

Send a ping about every 20 seconds. After a successful auth, the server closes the connection if it receives no inbound message for 75 seconds. On testnet the gateway may close an idle connection sooner than 75 seconds, so keep sending ping.

Unauthenticated connections are closed after 10 seconds.

Request Example​

{
    "op": "ping"
}

Response Example​

{
    "retCode": 0,
    "retMsg": "OK",
    "op": "pong",
    "data": [
        "1711002002529"
    ],
    "connId": "cnt5leec0hvan15eukcg-2v"
}
